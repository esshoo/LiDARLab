# LiDAR Lab

تطبيق iOS عام لتجربة قدرات LiDAR وARKit وRealityKit وحساسات الجهاز، بدون تخصيصه لمجال هندسي أو عقاري بعينه.

## النسخة 0.2.0

### وظائف تعمل الآن

- **معلومات الجهاز:** فحص دعم ARKit وScene Depth وSmoothed Depth وScene Mesh.
- **كاميرا العمق:** عرض الكاميرا مع خريطة حرارية للعمق وإحصاءات مباشرة.
- **قياس المسافة:** قراءة المسافة من مركز الشاشة بالمتر أو السنتيمتر.
- **ميزان الميل والزاوية:** خطوط أفقية ورأسية مرتبطة بالجاذبية، مع وضع تلقائي لاكتشاف اللوحات والإطارات ووضع يدوي بخط قابل للنقل والتدوير.
- **شبكة المكان:** عرض Scene Mesh الناتج من LiDAR وإحصاءات الرؤوس والمثلثات.
- **مختبر AR:** الضغط على الأسطح لوضع مكعبات افتراضية وتحريكها وتدويرها وتكبيرها.
- **اختبار ثبات الحساس:** جمع قراءات العمق لمدة 5 أو 10 أو 20 ثانية وحساب المتوسط والمدى والانحراف المعياري.

### ميزان الميل والزاوية

#### الوضع التلقائي

1. افتح **ميزان الميل والزاوية**.
2. وجّه الكاميرا إلى لوحة، إطار، شاشة، باب، أو جسم مستطيل واضح.
3. اضغط على الجسم مباشرة، أو استخدم زر **اكتشاف اللوحة**.
4. يعرض التطبيق حدود الأجسام المكتشفة، ويحدد أقرب ضلع إلى الأفقي.
5. راقب قيمة **الميل عن الأفقي** حتى تصل إلى `0.0°` تقريبًا.

> يعتمد الاكتشاف التلقائي على وضوح الحواف والإضاءة والتباين. الزجاج أو الحواف غير الواضحة قد لا تُكتشف بصورة مستقرة.

#### الوضع اليدوي

1. اختر **يدوي**.
2. اضغط على الشاشة لنقل الخط إلى حافة اللوحة.
3. اسحب الدائرة الوسطى لتحريك الخط.
4. اسحب دائرة التدوير لتغيير زاوية الخط، أو استخدم شريط الضبط الدقيق.
5. يقارن التطبيق الخط اليدوي بخطي الجاذبية الأفقي والرأسي.

### الواجهات المتجاوبة

- شبكة متكيفة بدل عدد أعمدة ثابت.
- عمود واحد عند ضيق الشاشة أو استخدام أحجام خطوط Accessibility.
- عمودان على أغلب هواتف iPhone.
- 3 أو 4 أعمدة على أجهزة iPad حسب العرض.
- القوائم ولوحات التحكم والقياسات تتحول تلقائيًا بين التخطيط الأفقي والرأسي عند عدم توفر المساحة.
- حد أقصى لعرض المحتوى على الشاشات الكبيرة حتى لا تتمدد العناصر بصورة مبالغ فيها.

### وظائف ظاهرة في القائمة وتحمل علامة «قريبًا»

- Point Cloud
- تصنيف الأسطح
- اكتشاف المستويات
- صورة مع العمق
- مسح الغرفة
- تسجيل الجلسات
- مركز التصدير

## البناء بدون Mac

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل Workflow باسم **Build LiDAR Lab Unsigned IPA**.
4. نزّل ملف الـArtifact بعد نجاح البناء.
5. فك الضغط لتحصل على `LiDARLab-unsigned.ipa` ثم وقّعه وثبّته بالطريقة التجريبية التي تستخدمها.

> GitHub Actions يتحقق من البناء وينشئ IPA غير موقع. اختبار LiDAR والحركة واكتشاف اللوحات يحتاج جهاز iPhone أو iPad فعليًا.

## متطلبات التشغيل

- iOS 17 أو أحدث.
- جهاز يدعم ARKit.
- وظائف العمق والـMesh تحتاج جهازًا مزودًا بـLiDAR.
- ميزان الميل يستخدم ARKit وCore Motion وVision، ويمكنه العمل على جهاز يدعم World Tracking حتى لو لم يكن مزودًا بـLiDAR.

## بنية المشروع

- `App/`: نقطة تشغيل التطبيق.
- `Core/`: نماذج الوظائف وفحص قدرات الجهاز.
- `Features/`: الشاشات العملية والقادمة.
- `Shared/`: مكونات واجهة مشتركة.
- `Resources/`: App Icon وAccent Color.
- `project.yml`: توليد مشروع Xcode باستخدام XcodeGen.
- `.github/workflows/`: بناء unsigned IPA عبر GitHub Actions.
