# LiDAR Lab

تطبيق iOS عام لتجربة قدرات حساس LiDAR وواجهات ARKit وRealityKit، بدون تخصيصه لمجال هندسي أو عقاري بعينه.

## النسخة الأولية 0.1.0

### وظائف تعمل الآن

- **معلومات الجهاز:** فحص دعم ARKit وScene Depth وSmoothed Depth وScene Mesh.
- **كاميرا العمق:** عرض الكاميرا مع خريطة حرارية للعمق وإحصاءات مباشرة.
- **قياس المسافة:** قراءة المسافة من مركز الشاشة بالمتر أو السنتيمتر.
- **شبكة المكان:** عرض Scene Mesh الناتج من LiDAR وإحصاءات الرؤوس والمثلثات.
- **مختبر AR:** الضغط على الأسطح لوضع مكعبات افتراضية وتحريكها وتدويرها وتكبيرها.

### وظائف ظاهرة في القائمة وتحمل علامة «قريبًا»

- Point Cloud
- تصنيف الأسطح
- اكتشاف المستويات
- صورة مع العمق
- مسح الغرفة
- اختبارات الحساس
- تسجيل الجلسات
- مركز التصدير

## الواجهة

يمكن التبديل بين عرض **الشبكة** وعرض **القائمة**. كل وظيفة لها أيقونة، وصف، وحالة واضحة: جاهز، قريبًا، أو غير مدعوم على الجهاز.

## البناء بدون Mac

1. أنشئ مستودع GitHub جديدًا.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. افتح تبويب **Actions**.
4. شغّل Workflow باسم **Build LiDAR Lab Unsigned IPA**.
5. نزّل ملف الـArtifact بعد نجاح البناء.
6. فك الضغط لتحصل على `LiDARLab-unsigned.ipa` ثم وقّعه وثبّته بالطريقة التجريبية التي تستخدمها.

> المحاكي وGitHub Actions يستطيعان التحقق من البناء فقط. اختبار LiDAR الحقيقي يحتاج جهاز iPhone أو iPad يحتوي على الحساس.

## متطلبات التشغيل

- iOS 17 أو أحدث.
- جهاز يدعم ARKit.
- وظائف العمق والـMesh تحتاج جهازًا مزودًا بـLiDAR.

## بنية المشروع

- `App/`: نقطة تشغيل التطبيق.
- `Core/`: نماذج الوظائف وفحص قدرات الجهاز.
- `Features/`: الشاشات العملية والقادمة.
- `Shared/`: مكونات واجهة مشتركة.
- `Resources/`: App Icon وAccent Color.
- `project.yml`: توليد مشروع Xcode باستخدام XcodeGen.
- `.github/workflows/`: بناء unsigned IPA عبر GitHub Actions.
