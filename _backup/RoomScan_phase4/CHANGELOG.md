# Changelog

## 0.12.0

- إضافة حفظ `ARWorldMap` قبل التوقف المؤقت وقبل تثبيت الغرفة.
- حفظ صورة مرجعية لآخر موضع للمساعدة أثناء إعادة تحديد الموقع.
- إضافة مجلد `Resume` داخل مشروع المسح وملفي `world-map.arexperience` و`relocalization-reference.jpg`.
- ترقية `session-checkpoint.json` إلى schema 2 مع الحفاظ على قراءة ملفات 0.11.0.
- اكتشاف أحدث مشروع غير مكتمل تلقائيًا عند فتح وظيفة مسح الغرف.
- تحميل الغرف والأجزاء وبيانات سماكات الحوائط من الملفات بعد إعادة تشغيل التطبيق.
- تشغيل `ARWorldTrackingConfiguration` باستخدام `initialWorldMap` ومحاولة مطابقة البيئة السابقة.
- انتظار حالة تتبع طبيعية لعدة إطارات قبل السماح باستكمال RoomPlan.
- إضافة شاشة صورة مرجعية وحالة التتبع وإعادة المحاولة عند فشل المطابقة.
- السماح باعتماد أجزاء الغرفة المحفوظة حتى عند تعذر المطابقة المكانية.
- محاولة حفظ تلقائي عند انتقال التطبيق إلى الخلفية أثناء مسح نشط.
- منع الرجوع من شاشة المسح أثناء الحفظ أو المطابقة لتجنب قطع المعالجة.
- إضافة نسخة احتياطية لملفات مرحلة 0.11.0 داخل `_backup/RoomScan_phase3`.
- تحديث الإصدار إلى `0.12.0` ورقم البناء إلى `15`.

## 0.11.0

- إضافة زر **توقف مؤقت** أثناء مسح الغرفة.
- إيقاف جلسة RoomPlan والكاميرا عبر `stop(pauseARSession: true)` مع معالجة النتيجة الحالية كجزء مستقل.
- إضافة شاشة سوداء واضحة عند التوقف المؤقت مع زر استكمال الغرفة.
- استكمال الغرفة بجلسة RoomPlan جديدة مرتبطة بنفس رقم الغرفة ونفس `ARSession` داخل تشغيل التطبيق الحالي.
- دعم تكرار التوقف والاستكمال أكثر من مرة داخل الغرفة نفسها.
- إضافة خيار اعتماد الأجزاء المحفوظة وإنهاء الغرفة دون إعادة فتح الكاميرا.
- تجميع حوائط أجزاء الغرفة في نموذج التطبيق، ومنع اعتبار تكرار الحائط بين أجزاء الغرفة حائطًا مشتركًا بين غرفتين.
- إضافة مطابقة مستقلة للحائط المستكمل بين الأجزاء المتتالية مع مصدر `continuedFragment`.
- حفظ كل جزء في `FrozenRooms/Room-XX/Fragments/Fragment-YY/room.json`.
- إضافة `fragments.json` لكل غرفة و`session-checkpoint.json` للمبنى.
- استخدام جميع الأجزاء عند إنشاء نموذج `StructureBuilder` للمقارنة، مع بقاء ملفات الأجزاء الأصلية مصدر الحقيقة.
- إضافة نسخة احتياطية لملفات مرحلة سماكات الحوائط داخل `_backup/RoomScan_phase2`.
- تحديث الإصدار إلى `0.11.0` ورقم البناء إلى `14`.
