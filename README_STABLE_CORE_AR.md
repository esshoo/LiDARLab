# 3ELiDAR v0.5.0 — Stable Core Rebuild

هذه النسخة أعيد بناؤها من أساس v0.3.1 بدل الاستمرار فوق Capture Core الخاص بسلسلة v0.4.x.

## الأولويات

1. تحديد موقع الجهاز وتسجيل كل Pose أولًا.
2. مسح 2D مع ربط Depth بنفس Frame ID.
3. إغلاق الالتقاط وحفظ الملف الخام.
4. بدء المعالجة محليًا فقط بعد أمر المستخدم.

## قواعد لا تتغير

- لا توجد معالجة حوائط أو نقاط ثقيلة أثناء الالتقاط.
- لا تتحكم الشبكة أو Preview أو Depth في تسجيل Pose.
- الملف الخام Append-only ولا توجد حدود حذف صامتة.
- Preview لها معدل مستقل، وأي تقليل فيها لا يمس البيانات الخام.
- المسار لا يُوصل عبر فقد التتبع أو فجوة زمنية أو قفزة غير منطقية.
- وضع تحديد الموقع لا يطلب sceneDepth.
- المعالجة توقف ARKit أولًا ثم تقرأ `raw_stream.3eld` المحفوظ.
- لم يتم تعديل أي ملف داخل `Features/RoomScan`.

## اختبار القبول الأول

- ضع الجهاز ثابتًا دقيقة كاملة.
- امشِ في خط مستقيم وارجع لنقطة البداية.
- افتح الإعدادات وأغلقها أثناء التسجيل.
- كرر الاختبار بوضع تحديد الموقع ثم بوضع 2D.
- قارن المرسل وWindows، مع مراجعة عدد فواصل التتبع.
