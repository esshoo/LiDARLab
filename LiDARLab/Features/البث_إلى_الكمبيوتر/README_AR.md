# البث إلى الكمبيوتر

ميزة مستقلة لا تستخدم أي ملف من `RoomScan`.

الإصدار الأول يرسل فقط:

- رقم الجلسة والإطار.
- وقت الإطار.
- موضع الهاتف واتجاهه من ARKit.
- حالة تتبع ARKit.
- حالة حرارة الجهاز.

عنوان الاتصال الافتراضي:

`ws://<WINDOWS-IP>:8766/ws/device`

لا يتم حاليًا إرسال العمق أو الصورة أو بناء Mesh على الهاتف، حتى يظل الحمل منخفضًا ونثبت أولًا مسار الموقع الحقيقي.
