# البث والمسح 2D

وظيفة مستقلة عن RoomScan لإرسال البيانات إلى مستقبل Windows أو مستقبل آخر مستقبلًا.

## v0.3.1

- فصل معدل إرسال موقع الجهاز عن معدل إرسال المسح 2D.
- يمكن اختيار Pose بسرعة 30 FPS مع Scan بسرعة 5 أو 10 FPS.
- كل Scan يرسل معه Pose تحمل نفس Frame ID لضمان التطابق.
- إعدادات النقل لا تتغير تلقائيًا أثناء الجلسة.
- إعدادات الحرارة تظل اختيارية وواضحة للمستخدم.

## البيانات الحالية

- Pose
- Quaternion
- Tracking State
- Thermal State
- Depth Grid مخففة
- Confidence Map اختيارية
- Camera Intrinsics
