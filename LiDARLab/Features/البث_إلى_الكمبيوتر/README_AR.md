# البث والمسح 2D

وظيفة مستقلة لا تعدّل RoomScan.

## الوضعان

- **الموقع فقط:** يرسل Pose الجهاز.
- **مسح 2D:** يرسل Pose + شبكة Depth مخففة.

## طريقة تقليل الحمل

لا يبني الهاتف Point Cloud ولا Mesh ولا يحلل الحوائط. يقرأ `sceneDepth`، يأخذ عينة كل 4 بكسلات تقريبًا، يحول العمق إلى ملليمترات، ويرسل البيانات إلى المستقبل. عند ارتفاع الحرارة إلى Serious يزيد التخفيف، وعند Critical يوقف إرسال العمق ويحافظ على Pose.

## ما يفعله الكمبيوتر

- يطابق Pose وDepth بنفس Frame ID.
- يعيد بناء الأشعة باستخدام Intrinsics.
- يحول النقاط إلى الإحداثيات العالمية.
- يرشح شريحة أفقية حول الجهاز.
- يرسم خريطة X/Z ثنائية الأبعاد.
