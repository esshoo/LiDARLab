# البث والمسح 2D — v0.3

وظيفة مستقلة لا تعدّل RoomScan.

## قاعدة إعدادات النقل

لا يغيّر التطبيق معدل الإرسال أو خطوة العينات أو Confidence تلقائيًا. المستخدم يختار القيم من قسم **إعدادات نقل البيانات** قبل بدء الإرسال.

## الاختيارات

- **نوع الإرسال:** الموقع فقط أو مسح 2D.
- **معدل الإرسال:** 1 / 2 / 5 / 10 / 15 / 30 FPS.
- **خطوة أخذ العينات:** 2 / 4 / 6 / 8 / 12.
- **Confidence:** إرسال أو عدم إرسال. إيقافه يوفر بايتًا لكل عينة Depth.
- **سياسة الحرارة:** تنبيه فقط، إيقاف Depth عند Critical، أو إيقاف كل الإرسال عند Critical.

القيمة الافتراضية لسياسة الحرارة هي **تنبيه فقط — لا تغيير تلقائي**.

## ما يفعله الهاتف

- يرسل Pose.
- يرسل شبكة Depth بالحجم الذي اختاره المستخدم.
- يرسل Confidence فقط عندما يكون الخيار مفعّلًا.
- لا يبني Point Cloud أو Mesh ولا يستخرج الحوائط.

## ما يفعله الكمبيوتر

- يطابق Pose وDepth بنفس Frame ID.
- يعيد بناء النقاط على X/Z.
- يحتفظ بالنقاط الخام.
- ينظف الخريطة بإعدادات قابلة للتعديل.
- يستخرج خطوط الحوائط والزوايا كطبقات مستقلة.
