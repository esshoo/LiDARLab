# نظام المسح الموحد v0.4

هذه الميزة مستقلة عن `RoomScan` ولا تعدّل أي ملف داخله.

## أدوار الجهاز

- **إرسال البيانات:** إرسال الجلسة إلى Windows أو جهاز Apple آخر.
- **استقبال البيانات ومعالجتها:** استقبال الجلسة من iPhone/iPad وحفظها. المعالجة على Apple ستضاف بعد ثبات صيغة الجلسة.
- **الالتقاط والمعالجة على هذا الجهاز:** التقاط وحفظ محلي، ثم تصبح الجلسة جاهزة للمعالجة بعد الإنهاء.

## أوضاع المسح

- مسار الجهاز: يعمل الآن.
- مسح 2D: يعمل الآن باستخدام Pose + شبكة Depth حسب الإعدادات.
- 3D بدون ألوان: ظاهر وقابل للتجربة، لكن v0.4 يسجل Pose فقط ولا يدعي تسجيل 3D.
- 3D بالألوان: ظاهر وقابل للتجربة، لكن حمولة RGB/3D لم تضف بعد.

## قاعدة v0.4

أثناء التسجيل لا توجد معالجة حوائط أو زوايا أو Mesh. التطبيق:

1. يلتقط الحزم المختارة.
2. يرسلها و/أو يكتبها إلى `Documents/3ELiDAR/Sessions`.
3. يعرض فقط مسارًا وتغطية تقريبية خفيفة.
4. يغلق الملف نهائيًا عند الضغط على **إنهاء**.

كل إعداد يؤثر في معدل البيانات أو حجمها ظاهر داخل نافذة الإعدادات ولا يتغير تلقائيًا.

## الاتصال بين أجهزة Apple

جهاز المستقبل يعلن عن نفسه بخدمة Bonjour:

```text
_3eld._tcp
```

المنفذ الافتراضي للاستقبال المباشر هو `8767`. ويمكن للمرسل استخدام جهاز مكتشف تلقائيًا أو IP يدويًا.
