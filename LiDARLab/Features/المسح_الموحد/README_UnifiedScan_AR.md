# المسح الموحد v0.4.3

الميزة تجمع أدوار الإرسال والاستقبال والعمل المستقل داخل واجهة واحدة.

## أثناء الجلسة

- التقاط وإرسال أو حفظ البيانات الخام.
- عرض مكان الجهاز ومساره وتغطية مكانية خفيفة.
- التغطية تراكمية بخلايا مكانية فريدة ولا تختفي بمرور الوقت.
- لا توجد معالجة حوائط أو زوايا أو Mesh أثناء التسجيل.

## بعد إنهاء الجلسة

تغلق الجلسة الخام أولًا، ثم يختار المستخدم إعدادات المعالجة ويبدأها يدويًا على الجهاز المستقبل أو الكمبيوتر.

## أساليب العرض

- التغطية: نقاط، خلايا ممتلئة، شبكة خلايا، تغطية حرارية.
- المسار: خط، نقاط، خط ونقاط.
- الجهاز: هاتف ومجال رؤية، هاتف فقط، سهم.

الأساليب السابقة تغير الرسم فقط ولا تغير أو تختصر البيانات المسجلة.
